### ₿ Bitcoin Knots Verified Update Automation

Built a Bash-based automated update system for a self-hosted Bitcoin Knots full node.

**Technologies:**

`Bash` `Linux` `GPG` `SHA-256` `systemd` `systemd timers`

**Security controls:**

- GPG signature verification
- Trusted signing-key verification
- SHA-256 integrity verification
- Binary backups before upgrades
- Automated service restart
- Post-update health verification

The system automatically checks for new releases and only installs software after verification succeeds.
